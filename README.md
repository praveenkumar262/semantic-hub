# Semantic Hub – Automated Semantic Modelling Platform

Semantic Hub is a data engineering platform designed to automate the creation of analytics-ready semantic layers by extracting metadata from Delta Lake tables and generating standardized semantic models.

## Key Capabilities
- Automated metadata extraction from Delta Lake tables
- Relationship and pattern detection for datasets
- Rule-based semantic model generation for BI tools
- Consistent definition of metrics, KPIs, and business logic
- UI-based interaction using Streamlit

## Architecture Overview
The solution follows a lakehouse-based approach, leveraging metadata-driven logic to standardize semantic definitions and reduce manual BI modeling effort.

## Tech Stack
- Python
- PySpark
- Databricks
- Delta Lake
- Streamlit
- Power BI (Semantic Layer)
- Azure Data Lake

## Project Scope
This repository demonstrates how metadata, semantic rules, and UI-driven workflows can be combined to accelerate analytics development and improve data consistency across reporting platforms.
